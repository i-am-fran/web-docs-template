# Home Page + Docs as Secondary Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the current single-page docs template into a home page (`index.html`) and a docs page (`docs.html`), sharing one topnav/footer chrome and one `css/style.css` / `js/script.js`.

**Architecture:** Plain HTML/CSS/JS, no build step. `docs.html` is the current `index.html` content verbatim, with topnav/footer branding updated. `index.html` becomes a new hero/features/CTA page reusing the same design tokens. `css/style.css` and `js/script.js` are extended in place, not duplicated.

**Tech Stack:** Static HTML, CSS custom properties, vanilla JS (IIFE in `js/script.js`). No test runner exists in this repo — verification is grep-based structural checks plus manual browser opens (`open index.html` / `open docs.html` on macOS).

## Global Constraints

- No build step, no npm, no framework — every file must work opened directly in a browser (spec: "File structure").
- Reuse existing design tokens (zinc grayscale, amber accents, IBM Plex Sans/Inter/Cascadia Code, `:root.dark` dark-mode pattern) — do not introduce `markdown-do`'s flexoki palette (spec: "New CSS").
- Topnav logo text becomes plain `"Project"` (no `/docs` suffix) on both pages, linking to `index.html` (spec: "Shared chrome changes").
- Footer copyright becomes `"© 2026 Project"` (same markup shape, drop the `/docs` span) on both pages (spec: "Shared chrome changes").
- Home page content is placeholder/generic, not a description of this template itself (spec: "Home page content").
- No screenshot/showcase section, no CLI/code-example section on the home page (spec: "Home page content", explicitly out of scope).
- `js/script.js`'s `initSidebarToggle` / `initSidebarDismissal` must not throw when `#sidebar`/`#sidebarToggle`/`#sidebarOverlay` are absent (spec: "JS fix required").
